# MOBILE TESTING (Android application)

## Setting Up Mobile Testing, Used Appium with java, Frame work as TestNG, Android studio. 
## Per-requesting setup.
* Install **Java & Node**
* Install the **Android SDK** to support the project.
* setup (Java,Android SDK & Node)Home path in Windows system
* Open Android Studio and Configure Emulator 
* Install and start the Appium Server via Node 
* Install the appium inspector to find the elements in application.

## How to use the android studio to Virtual device 
After installing android studio create a new project give some time to configuration. 
* Then go to **tools** in the menu bar click device manager. 
* click the **+** icon to create android virtual device. 
* select the phone with different pixels.
* select next to add **AVD NAME** please remember the name give to device.   
* Then click **finish** button to view the virtual device that open in screen. 
# How to install appium in windows 
please do install the **node**,and set up the home path in the environment variable or else the appium will not support to execute.  
* To start the **Appium server** use this **npm install appium** command on the command prompt.
* To install appium global level in your system use **npm install -g appium**
